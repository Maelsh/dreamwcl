## 🚀 كيفية التشغيل

### 1. تشغيل Frontend
```bash
cd duelik-platform
python3 -m http.server 8000
# افتح: http://localhost:8000
```

### 2. تشغيل Backend
```bash
cd duelik-platform/backend/
cp .env.example .env
npm install
npm run dev
# الخادم يعمل على: http://localhost:3001
```

### 3. اختبار النظام
```bash
# صفحة التشخيص الشاملة
open http://localhost:8000/debug.html

# اختبار سريع
open http://localhost:8000/quick-test.html
```
