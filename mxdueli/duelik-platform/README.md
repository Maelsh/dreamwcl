# منصة Dueli - منصة المنافسات التفاعلية

## نظرة عامة

منصة Dueli هي منصة تواصل اجتماعي متطورة مخصصة للمنافسات التفاعلية، مصممة لتحول النزاعات إلى حوار حضاري وإشراك الجمهور في العلم والمواهب بطريقة عادلة وشفافة.

## المميزات الرئيسية

### 🏆 **نظام المنافسات الشامل**
- **ثلاثة أقسام رئيسية**: الحوار، العلوم، المواهب
- **منافسات مباشرة**: بث مباشر مدمج مع YouTube API
- **تقييمات فورية**: نظام تقييم بالنجوم من الجمهور
- **شفافية مالية**: 80% للمتنافسين، 20% للإدارة
- **غرفة منافسة متطورة**: بث مباشر مع دردشة تفاعلية

### 👥 **إدارة المستخدمين المتقدمة**
- **أربعة أنواع مستخدمين**: متنافس، مشاهد مسجل، مشاهد غير مسجل، مدير
- **نظام المصادقة**: تسجيل دخول وإنشاء حسابات جديدة
- **اختيار نوع الحساب**: متنافس أو مشاهد مع إعدادات مخصصة
- **نظام المتابعة**: متابعة المستخدمين والمنافسات
- **بروفايل شخصي**: إحصائيات شاملة وإنجازات

### 💬 **التفاعل المباشر**
- **دردشة مباشرة**: مع فلترة حسب نوع المستخدم
- **إشعارات فورية**: تحديثات فورية عبر WebSockets
- **نظام الرسائل**: مراسلة مباشرة بين المستخدمين
- **تقييمات فورية**: نظام تقييم بالنجوم أثناء البث

## التقنيات المستخدمة

### Frontend
- **HTML5**: هيكل الصفحة الدلالي
- **CSS3**: 
  - CSS Grid و Flexbox للتخطيط
  - CSS Variables لسهولة الإدارة
  - Animations و Transitions
  - Media Queries للتصميم المتجاوب
- **JavaScript ES6+**: 
  - Programmatic DOM manipulation
  - Event handling متقدم
  - Intersection Observer للأداء
  - Accessibility features

### **التصميم**
- **نظام ألوان متطور**: Dark mode first
- **typography**: Poppins + Inter fonts
- **تأثيرات متحركة**: CSS transitions & animations
- **تصميم متجاوب**: Mobile-first approach

### **PWA (Progressive Web App)**
- **Service Worker**: تخزين مؤقت ذكي
- **Manifest**: تطبيق قابل للتثبيت
- **Offline Support**: عمل دون اتصال
- **Push Notifications**: إشعارات فورية

### **إمكانية الوصول**
- **WCAG AAA**: معايير إمكانية الوصول
- **ARIA labels**: دعم قارئات الشاشة
- **Keyboard navigation**: تنقل كامل بلوحة المفاتيح
- **High contrast**: تباين ألوان عالي

## الصفحات والمكونات

### 1. **الصفحة الرئيسية** (`index.html`)
- عرض المنافسات الشائعة مع تمرير أفقي
- تبويبات التصفية (الجميع، حي، مسجل)
- أقسام المنافسات (الحوار، العلوم، المواهب)
- تصميم بطاقات تفاعلي مع معلومات شاملة

### 2. **نظام المصادقة**
- **تسجيل الدخول** (`auth/login.html`)
  - نموذج تسجيل دخول أنيق
  - تكامل مع الشبكات الاجتماعية
  - تذكر بيانات الدخول
  - إعادة تعيين كلمة المرور
- **التسجيل** (`auth/register.html`)
  - اختيار نوع المستخدم (متنافس/مشاهد)
  - التحقق من كلمة المرور
  - اختيار الدولة واللغة المفضلة
  - قبول الشروط والأحكام

### 3. **لوحة التحكم** (`dashboard.html`)
- إحصائيات شخصية شاملة
- آخر المنافسات مع الحالة
- المنافسات الشائعة
- توصيات المستخدمين للمتابعة
- إجراءات سريعة لإنشاء منافسة جديدة

### 4. **إنشاء المنافسة** (`create-challenge.html`)
- نموذج متعدد المراحل (4 خطوات)
- اختيار القسم والمجال الفرعي
- تفاصيل المنافسة والقوانين
- جدولة المنافسة
- مراجعة وإعدادات البث

### 5. **غرفة المنافسة** (`challenge-room.html`)
- بث مباشر مدمج مع YouTube
- دردشة تفاعلية مع فلترة
- نظام التقييم بالنجوم الفوري
- أدوات تحكم للمتنافسين
- لوحة إشراف للمدراء
- إحصائيات مباشرة

### 6. **البروفايل الشخصي** (`profile.html`)
- معلومات المستخدم الشاملة
- سجل المنافسات مع فلترة
- الإنجازات والشارات
- نظام المتابعة
- إحصائيات مفصلة

## دليل الاستخدام

### التثبيت والإعداد

#### **المتطلبات**
- خادم ويب محلي (Python, Node.js, أو خادم آخر)
- متصفح حديث يدعم ES6+
- YouTube API key (اختياري للبث المباشر)

#### **التثبيت السريع**
```bash
# تحميل المشروع
git clone [repository-url]
cd duelik-platform

# تشغيل خادم محلي (Python)
python3 -m http.server 8000

# أو استخدام Node.js
npx serve -s . -l 3000

# أو PHP
php -S localhost:8000

# فتح المتصفح
open http://localhost:8000    # macOS
start http://localhost:8000   # Windows
xdg-open http://localhost:8000 # Linux
```

#### **خادم الإنتاج**
```bash
# Nginx
sudo cp nginx.conf /etc/nginx/sites-available/duelik
sudo ln -s /etc/nginx/sites-available/duelik /etc/nginx/sites-enabled/

# Apache
sudo cp .htaccess /var/www/html/.htaccess

# إعادة تشغيل الخادم
sudo systemctl restart nginx  # أو apache2
```

### **التطوير**
```bash
# تثبيت التبعيات (إذا لزم الأمر)
npm install

# تشغيل في وضع التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```

### التصفح والبحث
- **البحث**: استخدم مربع البحث العلوي أو اختصار Ctrl+K
- **التصفية**: استخدم تبويبات "الجميع"، "حي"، "مسجل"
- **التصفح**: انقر على أي بطاقة منافسة للعرض
- **التنقل**: استخدم الأسهم للتنقل بين التبويبات

### الاختصارات
- `Ctrl+K`: التركيز على مربع البحث
- `Escape`: إغلاق النوافذ أو مسح البحث
- الأسهم: التنقل بين التبويبات
- `Enter` أو `Space`: تفعيل العناصر المحددة

## التطوير والتخصيص

### إضافة منافسات جديدة
```html
<div class="competition-card" data-id="unique-id">
    <div class="video-thumbnail">
        <!-- لقطة الفيديو -->
    </div>
    <div class="competitors-info">
        <!-- معلومات المتنافسين -->
    </div>
    <div class="competition-details">
        <!-- تفاصيل المنافسة -->
    </div>
</div>
```

### تخصيص الألوان
عدّل متغيرات CSS في `:root`:
```css
:root {
    --primary-500: #0A84FF;    /* اللون الأساسي */
    --bg-surface: #1C1C1E;     /* لون الأسطح */
    --text-primary: #E4E4E7;   /* لون النص الأساسي */
}
```

### إضافة أقسام جديدة
1. أضف قسم HTML جديد في `index.html`
2. أضف معالج JavaScript في `main.js`
3. طوّر تصفية مخصصة للمحتوى
